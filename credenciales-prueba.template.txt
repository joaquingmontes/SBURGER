CONFIG FIREBASE EN LA APP
-------------------------
Copiá app/src/config/firebaseConfig.example.ts → firebaseConfig.ts
y completá los valores desde Firebase Console → Project settings → Web app.

SETUP FIREBASE LOCAL
--------------------
1) Copiá .firebaserc.example → .firebaserc
2) Copiá firebase.json.example → firebase.json
3) Copiá storage.rules.example → storage.rules (opcional)
4) Copiá dataconnect.example/ → dataconnect/
5) Editá dataconnect/dataconnect.yaml con tu serviceId, database e instanceId
6) Copiá scripts/*.example.* → scripts/ (sin .example) y completá usuarios/contraseñas
